## 受众与卖点

| 受众 | 他在意什么 | 片子里怎么给 |
| --- | --- | --- |
| 已经在用 DSH Web 的人 | 在终端里能不能一样顺手 | 真流式、工具折叠、块光标、审批 |
| 终端党 / tmux 用户 | 键位、速度、能不能 ssh | 全程键盘操作，无鼠标 |

三个关键词：**原生终端**、**真流式**、**会话是共享的**。

## 旁白逐字稿

1. dshell 是 DeepSeek Harness 的终端前端。
2. 它不接管你的 Agent，只是把同一个会话搬到终端里：流式输出、工具调用、审批，全都在。
3. 直接说需求，不需要记命令。
4. 回复是真流式出来的；每次工具调用折成一行，不刷屏。
5. Markdown 表格会按终端宽度重排；代码块原样保留，不做二次加工。
6. 想细看某一步，Alt+↑ 选中，Enter 打开详情。
7. Ctrl+O 把工具输出展开，再按一次收起。
8. `?` 随时打开键位速查。
9. 新的一轮跑起来后，还可以继续补充。
10. Enter 直接插话，内容折进当前回合的下一步。
11. 怕打断就用 Alt+Q 排队，当前回合结束后自动执行。
12. Ctrl-C 只打断当前这一轮，排队的请求会接着执行。
13. 会话列表按最后编辑时间排序，接手旧会话不用翻。
14. 需要审批的操作会弹在终端里，按 a 通过。
15. 安装好后，一个 `dshell` 就能开始。

## 录制方式

画面由 `demo.mjs` 驱动真实 TUI（`runTui` + `FakeBackend`，事件是脚本化的，
所以每次录出来一模一样）。`demo.mjs` 把 TUI 每次重绘的 ANSI 片段连同时间戳
记进 `out/frames.jsonl`；`render.py` 用一个小型屏幕模型回放这些片段，按 15fps
采样，套上窗口边框、字幕条、片头片尾，再由 ffmpeg 编码成 1080p30。

- 需要：`tmux`、`ffmpeg`、`python3` + `Pillow`、`fontTools`、Noto Sans Mono CJK；
- 一条命令：`docs/promo/record.sh`（≈2 分钟，含重录与编码）；
- 产物：`docs/promo/out/dshell-promo.mp4`、`poster.png`；
- 中间文件（帧、`frames.jsonl`、`captions.json`）不入库，随时可重生成。

改文案只需要改 `demo.mjs` 里的 `SCRIPT`，改字幕改 `caption()` 调用。
